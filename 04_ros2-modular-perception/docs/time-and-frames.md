# 时间、坐标帧与图像编码约定

## 1. 概念

| 字段 | 含义 | 本项目中的用途 |
|---|---|---|
| `header.stamp` | 这条消息对应的时间 | 让检测、跟踪和原始图像对应同一帧 |
| `header.frame_id` | 消息所属的坐标／来源帧名称 | 标识图像来自哪个逻辑相机来源 |
| 图像编码 | 像素通道的排列方式 | 让下游正确解释颜色 |
| 源视频帧时间 | 视频中该帧原本的时间位置 | 不用检测完成的当前电脑时间替代它 |

## 2. 本项目约定

当前输入是离线视频。

- 第 `i` 帧时间为：`t = i / FPS`。
- 后续发布图像时，`header.stamp` 使用该源视频帧时间。
- 当前没有相机标定和真实三维坐标系，`frame_id` 暂定为 `source_video_frame`。
- OpenCV `VideoCapture` 默认读取 BGR 顺序图像，因此未转换时使用 `bgr8`。
- 若后续把图像显式转换为 RGB，必须同步改为 `rgb8`。
- 检测和跟踪结果必须保留原始图像的 `header.stamp` 与 `frame_id`。

## 3. 当前边界

本约定只服务于离线视频回放与二维检测、跟踪。

它不表示已经完成：

- 相机标定；
- 相机坐标到世界坐标的转换；
- 三维定位；
- PX4、Gazebo 或真实传感器时间同步。
