# UAVDT 标注规范

## 适用范围

第一版使用 UAVDT 原始标注，不重新绘制原始框。转换时只改变类别编码，不改变原始框坐标；后续若补充其他视频，遵守本规范。

原始类别与项目类别：

~~~text
car / truck / bus -> vehicle
vehicle -> YOLO class 0
~~~

## 框边界

- 使用左上角坐标加宽高的原始框：left, top, width, height。
- 转换为 YOLO 时使用像素框中心和归一化宽高。
- 不把阴影、道路反光、拖影或相邻目标纳入框。
- 不凭想象补出被遮挡或出画的部分。

## 遮挡

UAVDT 的 occlusion 字段保留为元数据：1=no-occ、2=large-occ、3=medium-occ、4=small-occ。遮挡目标只要类别和可见框仍可确认，就保留原始框；不要为了提高训练集观感而删除困难样本。

## 截断和出画

out-of-view 字段保留为元数据：1=no-out、2=medium-out、3=small-out。不在图像范围外虚构框。超过边界且无法可靠判断为独立目标的区域由原始 gt_ignore 或原始数据规则处理。

## 小目标、重叠和模糊

- 原始有效框先全部保留；小目标漏检属于后续误差分析内容。
- 相互重叠的车辆分别保留独立框，不合并成一个大框。
- 运动模糊或压缩伪影下仍能确认车辆类别时保留；无法确认时不自行猜测。
- 若以后补标，短边小于 10 像素且无法稳定确认类别时，标记为难例并考虑从训练样本中排除，但保留在复核记录中。

## 忽略区域

*_gt_ignore.txt 中的框不是正常训练目标。评估时排除与忽略区域重叠的预测；转换为标准 YOLO 标签时不把忽略框写成 vehicle。如果某帧包含大量无法表达的忽略区域，优先记录该帧并在数据版本中明确处理方式。

## 难以判断情况

类别不清、严重遮挡、严重出画、框位置明显损坏或图像损坏时，不通过猜测修正原始标签。记录序列、帧号、问题类型和处理决定，以便误差分析和数据版本回溯。
